Patrones utilizados:
Nosotros utilizamos los patrones "Strategy" y "Polimorfismo" ya que para la implementación del sistema de respuestas por I.A cualquier modelo puede ser la que responde, independientemente el modelo los resultados deben ser los mismos. Además implementamos Polimorfismo para representar la implementación de clases que comparten métodos/comportamientos similares (como por ejemplo las clases "Pregunta" y "Respuesta" que se heredan de "Publicación").
